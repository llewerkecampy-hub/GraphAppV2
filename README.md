Publication-quality figures
Automatic statistical test selection
ANOVA, Tukey HSD
Mann-Whitney U
Kruskal-Wallis
Dunn's post hoc
Growth curves
Scatter plots
Box plots
Violin plots
SVG, PDF, TIFF export
